GitHub 토큰으로 바로 커밋하기 (선택)

연결하면 글 저장 / 상품 "GitHub 에 커밋" 이 저장소의 blog/posts.json, shop/products.json 을 직접 수정하고, Cloudflare Pages 가 node build.mjs 를 돌려 1~2분 안에 재배포합니다.

  1. github.com/settings/personal-access-tokens → Generate new token
  2. Repository access: "Only select repositories" → 내 사이트 저장소만
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate token → github_pat_... 복사
토큰은 이 브라우저의 localStorage 에 평문으로 저장됩니다. 본인 기기·본인 브라우저에서만 쓰고, 공용 PC 에서는 쓰지 마세요.
